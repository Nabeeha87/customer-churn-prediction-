# Strategic Data Analytics Framework

## Project

Customer Churn Prediction Using Python

## Objective

The project aims to analyze customer data, identify patterns associated with customer churn, and develop a strategy for predicting customers who may be likely to leave a service.

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Week 1

This week focuses on designing the strategic framework for the complete data analytics project, including the project objectives, data acquisition plan, data processing strategy, analysis approach, timeline, tools, expected outcomes, and risk mitigation.

## Week 2

This week focuses on developing the data acquisition and preprocessing strategy for the customer churn prediction project. The work includes identifying suitable customer data, understanding relevant features, checking data quality, handling missing values and duplicate records, validating data types, and preparing numerical and categorical data for further analysis and machine learning.
