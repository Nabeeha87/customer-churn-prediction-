# Week 1 – Strategic Data Analytics Framework

## Project
Customer Churn Prediction Using Python

## Objective
The project aims to analyze customer data, identify patterns associated with customer churn, and develop a strategy for predicting customers who may be likely to leave a service.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Week 1
This week focuses on designing the strategic framework for the complete data analytics project, including the project objectives, data acquisition plan, data processing strategy, analysis approach, timeline, tools, expected outcomes, and risk mitigation.

## Planned Project Effort
33 hours
